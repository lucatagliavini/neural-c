## Checkpoint 8.4.1 implementation

- New imports compute exact global test and validation counts with
  `floor(total_samples * ratio)` instead of flooring independently per class.
- Categorical quotas use deterministic largest-remainder apportionment. Test
  quotas are assigned first, validation quotas second. Equal remainders prefer
  the class with less existing holdout, then schema class order.
- Every class retains at least one training sample. An infeasible combined
  holdout fails before the existing project transaction is changed.
- Integer quota products use checked, architecture-independent long division,
  avoiding overflow and floating-point decisions during class apportionment.
- Per-class samples still use the specified SplitMix64 shuffle and generated
  native datasets still retain source order after assignment.

## Preprocessing compatibility

- New imports write `neural-c preprocessing 2` and persist
  `split_algorithm global_largest_remainder_v1`.
- Version 1 preprocessing remains readable and writable. Its omitted algorithm

- Existing version 1 projects and weights require no migration, regeneration,

  provenance and therefore requires fresh weights, as import already enforces.
- `inspect` now reports preprocessing format and split algorithm.
