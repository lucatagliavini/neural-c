## Training configuration and behavior

- `project.conf` accepts optional `batch_size`; new projects always materialize
  it and `init --batch-size N` configures it.
- Zero selects the historical full-dataset update and is also the value assigned
  to legacy project files that omit the property.
- A positive value partitions each epoch into deterministic contiguous
  source-order ranges. Each range produces one gradient update, and the final
  batch uses its actual sample count when it is incomplete.
- Values larger than the training sample count resolve to the complete dataset.
- Samples are not shuffled; deterministic shuffling remains Milestone 9.3.
- `inspect` reports either `Batch size: full dataset` or the configured value.

## API and deterministic execution

- The obsolete public names `neural_model_train_full_batch` and
  `neural_model_train_full_batch_range` were replaced by
  `neural_model_train` and `neural_model_train_range`.
- The persistent executor is reused across every batch. Worker scheduling and
  thread count do not change batch boundaries, ordered reduction, or model
  results.
- Epoch observers run only after every batch in the epoch has updated the model
  and the complete dataset loss has been evaluated.

## Persistence and continuation

- Positive `batch_size` is training-owned provenance and appends a
  `mini_batch` marker plus its configured value to the canonical training
  digest.
- Zero omits that marker, so legacy full-batch projects retain their exact
  canonical digest. The XOR digest remains
  `08778dfaba9557e47d924f3010e4b972935e718b994c3a65eb2f0aac5de4ab6d`.
- Weights and checkpoint payload versions are unchanged. Batch boundaries are
  derived from digest-bound project configuration, so changing the configured
  value invalidates existing persistence before mutation.
- Checkpoints remain completed-epoch snapshots. Graceful signals are observed
  at the next coherent epoch boundary; a hard failure cannot persist partial
  mini-batch progress, so resume starts from the previous checkpoint boundary.
